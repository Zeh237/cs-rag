The University of Buea manages a large collection of academic notes across many departments. Students and staff need fast access to correct information. Traditional keyword search does not understand meaning. Large Language Models can generate fluent text but can produce incorrect information without source documents. This project presents a general digital library system that uses Retrieval-Augmented Generation. The system can store documents from any faculty. It accepts PDF, Markdown and text files. The current case study uses Computer Science notes as a representative dataset. The system converts each PDF to Markdown. It tests four Text Extraction methods: Vision Language Model, fitz raw, fitz clean and plain text. It splits documents with five Chunking Strategies: fixed, recursive, semantic, document and hierarchical. Each chunk stores its word position and page number. The system creates vector embeddings and stores chunks and embeddings in Elasticsearch. A web interface provides search, chat, document ingestion and PDF viewing with highlighted sources. The evaluation has three tracks. The first track compares Text Extraction. The Vision Language Model produces the cleanest Markdown and keeps correct page markers. The other methods retain more noise. The second track compares Chunking Strategies. Hierarchical and semantic chunking do not split sentences. Fixed, recursive and document chunking split sentences in about 89 percent of cases. Hierarchical chunking covers all words and keeps chunks inside section boundaries. It uses parent chunks at two times the target size and child chunks at the target size. The third track evaluates search. It tests keyword, semantic, hybrid and hybrid plus rerank pipelines. It measures precision, recall, Mean Average Precision, Mean Reciprocal Rank, precision at k, recall at k and Normalized Discounted Cumulative Gain. The results show that Vision Language Model extraction with hierarchical chunking and hybrid plus rerank search gives the best balance of quality, speed and citation accuracy. The system provides a scalable digital library for the University of Buea and can host any academic collection.

Keywords: Digital Library, Retrieval-Augmented Generation, Text Extraction, Chunking Strategies, Vector Embeddings, Elasticsearch, Hybrid Search, Semantic Search, University of Buea
